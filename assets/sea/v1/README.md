# 海上保卫战 · 美术素材第一批

本批使用内置图像生成工具制作，采用精细半写实军事模型风格。完整生成提示词见 PROMPTS.md。

精选 9 项：海面背景、炮台底座、独立炮塔、巡逻艇、快艇、重装巡洋舰、潜艇、敌方旗舰、爆炸动画图集。海面为不透明 PNG，其余素材含 Alpha 透明通道。explosion-sheet-v1.png 为保留的早期草稿，当前选择 v2。

打开 index.html 可浏览素材并转动炮塔、预览爆炸；本地服务预览地址为 http://127.0.0.1:5174/art/sea/ 。画面为素材图层组合。同批素材已通过 sea-art.js 接入游戏，进入大厅的「海上保卫战」即可游玩。

舰船与炮管朝右。manifest.json 记录原始尺寸、建议锚点和用途；锚点为目测初值，接入时需校准。原图保持生成结果，未缩放或重绘。运行时建议另制较小纹理。

爆炸图集为 4×4 的 16 帧动画。游戏运行时使用整数边界采样，给每格边缘加柔化遮罩，并在尾帧淡出，避免串帧和突然消失。素材预览页仍显示原图逐格播放，未添加游戏内的边缘处理。
