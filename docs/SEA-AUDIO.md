# 海战武器音效

发射事件使用 `weapon:<id>`，每次齐射只发送一次，11 把武器分别选择自己的音色。普通命中、爆炸、过热和状态提示仍是独立事件。

音效是原创程序合成的拟真设计，不是真实武器录音。以宽频爆响、衰减金属共振、枪机动作和轻微室外反射构成；能量武器采用虚构的电弧、气流、低频冲击设计，去掉旧版明显的音高滑动。

| 武器 | 声音特点 |
| --- | --- |
| 轻型机枪 | 干脆短爆响，随后枪机回位 |
| 双联机枪 | 两个接近的枪口爆响，较厚的机械声 |
| 速射机炮 | 更低沉、紧凑的射击，缩短尾音避免连续射击混浊 |
| 标准舰炮 | 爆响、炮身震动、低频冲击与短余响 |
| 扩散火炮 | 三段紧密叠加的发射爆响 |
| 重型榴弹炮 | 更低沉的轰鸣、较长空气震动和重炮机构声 |
| 激光炮 | 短促电容放电、气流爆裂及散热声 |
| 电磁炮 | 尖锐瞬态、厚重冲击及金属机构回响 |
| 等离子炮 | 低频压力冲击和持续消退的能量燃烧声 |
| 冷冻机枪 | 机械点射和高压冷却气体喷射 |
| 电弧机枪 | 多段不均匀的放电噼啪声 |

每把武器最多缓存三种双声道样本，交替播放，避免逐帧合成。高射速去重间隔为 25ms，低于现有最大升级射速间隔，避免旧版能量机枪 150ms 去重造成丢声。单样本峰值不超过 0.86，保留总音量和动态压缩器；最多 32 个声源，满载时新武器声替换最旧声源。暂停、失焦和静音会停止所有声源。

验证包括 11 种武器的事件路由、不同波形、有限振幅、首尾无突变、样本缓存、最高射速和停声。浏览器 OfflineAudioContext 实际输出经压缩器的 29 秒试听，峰值约 0.314；桌面每种音色首次合成约 3–19ms（连射样本包含三个变体）。已在本地游客战斗中检查标准舰炮播放及暂停，无控制台错误。未做实体手机扬声器主观试听。

本机试听文件：`deploy/builds/weapon-sounds-preview.wav`。每隔 2.5 秒切换，依次为轻型机枪、双联机枪、速射机炮、标准舰炮、扩散火炮、重型榴弹炮、激光炮、电磁炮、等离子炮、冷冻机枪、电弧机枪。
