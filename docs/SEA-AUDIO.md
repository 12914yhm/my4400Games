# 海战武器音效

发射事件使用 `weapon:<id>`，每次齐射只发送一次，11 把武器分别选择自己的音色。普通命中、爆炸、过热和状态提示仍是独立事件。

常规武器现在采用 CC0 实录素材，剪辑和混音说明见 [音频来源](../assets/sea/audio-v1/CREDITS.md)。机枪来自 AK-47、Carl Gustav M45、PPSh 的现场单发录音；扩散火炮基于 Winchester Model 12；舰炮和重炮基于 qubodup 的 Cannon Shot。它们是游戏配音，不声称与虚构炮塔型号对应。能量武器仍采用程序设计音效，并增加衰减回响。

| 武器 | 声音特点 |
| --- | --- |
| 轻型机枪 | 干脆短爆响，随后枪机回位 |
| 双联机枪 | 两个接近的枪口爆响，较厚的机械声 |
| 速射机炮 | 更低沉、紧凑的射击，缩短尾音避免连续射击混浊 |
| 标准舰炮 | 爆响、炮身震动、低频冲击与短余响 |
| 扩散火炮 | 三段紧密叠加的发射爆响 |
| 重型榴弹炮 | 更低沉的轰鸣、较长空气震动和重炮机构声 |
| 激光炮 | 短促电容放电、气流爆裂及散热声 |
| 电磁炮 | 尖锐瞬态、厚重冲击及金属机构回响 |
| 等离子炮 | 低频压力冲击和持续消退的能量燃烧声 |
| 冷冻机枪 | 机械点射和高压冷却气体喷射 |
| 电弧机枪 | 多段不均匀的放电噼啪声 |

实录音频为 7 个 MP3 音频集合，合计约 1.07 MB：机枪三种，每种含三次真实单发；扩散火炮、舰炮和重炮各含两次；另有爆炸。页面提前下载，用户操作后解码；按实际射击事件播放对应切片。机枪保留 2.4 秒（含少量扩散混响），扩散炮 3.2 秒，标准舰炮 5.4 秒，重炮 6 秒。松开射击后继续播放尾音，暂停、静音和关闭立即停声。

高射速去重间隔 25ms；最多 64 个声源，容纳高射速与较长尾响重叠。总音量、动态压缩器和样本限幅避免连续射击时音量失控。原合成音色保留为加载中或下载/解码失败的降级方案；迟到的资源不会补播旧声音。

74 项测试通过，包括独立音效事件、预加载去重、用户操作后解码、录音切片轮换、加载失败降级、静音期间加载完成不补播、最高射速和暂停清理。浏览器实际解码全部 MP3 并经完整混音输出，连续射击加主炮预览峰值约 0.323，无控制台错误。未进行实体手机扬声器主观试听。

本机游戏混音试听：`deploy/builds/real-weapons-ingame.wav`，34 秒。顺序：轻型机枪（0 秒）、双联（4 秒）、速射（8 秒）、扩散（12 秒）、舰炮（17 秒）、重炮（24 秒）、爆炸（31 秒）。

重建：安装 numpy、soundfile、imageio-ffmpeg，按来源文档下载原包至本机临时目录，用 `python assets/sea/audio-v1/build.py <原素材目录>` 生成 MP3 和 manifest.json。原始 194 MB 枪械包不发布、不提交；只提交剪辑后的文件、来源和重建脚本。
