# 玩岛 PlayIsland

类似小游戏门户的首页框架，使用原生 HTML、CSS、JavaScript，无需安装前端依赖。

## 本地运行

已部署到阿里云 ECS：[在线试玩](https://47.107.99.105/games/)。发布、验证和回退说明见 `deploy/README.md`。

安装 Node.js 22 或更高版本后，在项目目录运行 `npm run dev`，访问 http://localhost:5173。可通过 `PORT` 环境变量更改端口。项目没有第三方 npm 依赖，无需安装依赖。

## 多人协作

代码仓库：[12914yhm/my4400Games](https://github.com/12914yhm/my4400Games)。当前完整代码在 `develop` 分支。

```sh
git clone --branch develop git@github.com:12914yhm/my4400Games.git
cd my4400Games
npm run dev
```

开发时从 `develop` 创建自己的功能或修复分支，完成后提交 PR 合并回 `develop`。具体流程见 [CONTRIBUTING.md](CONTRIBUTING.md)。

## 当前功能

- 响应式首页、分类导航、精选推荐切换、示例人气榜单。
- 实时搜索、分类筛选、推荐与最新排序、加载更多。
- 收藏及最近玩过记录保存在当前浏览器本地。
- 游戏详情弹窗，内置可玩的记忆翻牌示例。
- 「弹珠打砖块」：连续发射、数字方块、墙壁反弹、加球道具、回合下移、失败结算；支持鼠标、触屏与键盘、暂停、二倍速、提前收球和本地最高分。
- 「海上保卫战」玩法重制：固定海上炮台、机枪与范围主炮、快艇/巡逻艇/装甲舰/潜艇/旗舰、8 波进攻、波次间升级商店、4 种战术道具、失败与通关结算。美术及代码重新制作，非原版 Flash 文件或逐像素复刻。
- 自制 SVG 游戏插画，无外部图片依赖。字体加载失败时自动使用系统字体。

游戏列表中的评分、排序是展示数据；「记忆翻翻乐」「弹珠打砖块」「海上保卫战」可以直接游玩，其他游戏未接入，详情页已标注。账号通过用户名和密码注册；目前仅海战支持账号存档，没有真实排行榜。

## 文件

- `index.html`：页面结构。
- `styles.css`：桌面与移动端样式。
- `app.js`：示例数据、插画、页面交互及记忆翻牌小游戏。
- `server.js` / `accounts-api.js`：静态文件与账号、存档接口（Node 内置模块，无第三方依赖）。
- `accounts.js` / `accounts.css`：注册、登录、退出与手机适配。
- `sea-save.js`：浏览器与服务端共享的存档校验。
- `sea-weapons.js`：浏览器与服务端共享的武器目录、解锁关卡和基础数值。
- `balls-engine.js`：与画面独立的弹珠物理、计分及回合逻辑。
- `balls.js` / `balls.css`：弹珠游戏画面、控件与响应式弹窗。
- `sea-engine.js`：海战物理、敌舰行为、武器、道具、经济与波次状态。
- `sea.js` / `sea.css`：海战 Canvas 画面、音效、输入与商店界面。
- `sea-art.js`：按需载入并缓存海面、分层炮台、5 类敌舰与 16 帧爆炸，处理命中闪光及透明边缘。图片失败或超时会使用原有简化画面。
- `assets/sea/v1/`：原始美术、完整提示词与素材预览。游戏使用其中 9 项 PNG；原图不改动，运行时缓存较小纹理。
- `assets/sea/weapons-v1/`：六种武器的独立透明 PNG 和完整生成提示词。武器库展示素材图片，战场主炮与副武器随装备切换外观；新增图片不可用时保留原炮塔备用绘制。

后续可将 `app.js` 中的 `games` 数据拆分为独立模块或替换成接口，并在游戏详情中接入游戏页面。

执行 `npm run check` 检查 JavaScript 语法。
执行 `npm test` 验证两款游戏的核心逻辑，包括海战完整 8 波战役模拟。

## 海上保卫战操作

鼠标移动瞄准，按住左键使用机枪，空格使用主炮，1–4 分别使用维修、护盾、空袭和干扰，P 暂停。画布聚焦时也可使用左右方向键瞄准、F 使用机枪。手机按住画布目标射击，使用下方主炮和道具按钮；横屏更适合游玩。

手机进入海战时优先请求全屏和横屏锁定。浏览器不支持或拒绝时，竖屏显示旋转引导，手动横放后即可使用完整界面。不会要求安装应用或关闭浏览器安全设置。左手拖动摇杆瞄准并自动连射副武器，松手停火散热；右手可同时按住主炮按钮连续发射，也可点击道具。仍支持直接按住战场目标射击。按钮最小触控高度 44px，兼容屏幕安全区域。转回竖屏、退出全屏或切到后台时暂停；返回后手动继续。武器库与补给商店在手机上使用可滚动面板。

已用浏览器模拟验证 844×390、667×375 横屏布局和 390×844 竖屏引导；多指按压、取消、旋转与迟到的横屏锁定通过自动回归测试。实际自动横屏能力依赖设备和浏览器，尚未进行实体手机测试。参考：[Screen Orientation API](https://developer.mozilla.org/en-US/docs/Web/API/ScreenOrientation/lock)。

潜艇潜航时机枪无效，主炮和空袭仍可造成伤害。第 4、8 波有旗舰。商店只在波次结束时开放，库存和升级等级均有限制。登录后每 5 秒、暂停、关闭及购买升级时保存战役；再次进入会读取本账号进度，点击继续开始。游客战役和最高分不持久化。

战场上方显示当前主武器、副武器，点击「武器库」可查看全部武器及解锁要求。战斗中打开武器库会暂停；准备、补给或暂停时可以免费换装，再点击继续恢复战斗。换装不会清除热量或剩余冷却。

| 解锁关卡 | 武器 | 特点 |
| --- | --- | --- |
| 第 1 波 | 标准舰炮、轻型机枪 | 初始主武器与副武器 |
| 第 2 波 | 双联机枪 | 双管齐射 |
| 第 3 波 | 扩散火炮 | 三枚炮弹扇形发射 |
| 第 5 波 | 速射机炮 | 高频连射 |
| 第 6 波 | 重型榴弹炮 | 高伤害、大范围、较长冷却 |

完成前一波后，在补给阶段提前解锁下一波对应的武器，并显示提示。装备随账号战役保存，旧存档默认装备标准舰炮与轻型机枪，按存档关卡解锁武器。重新部署会开始新战役并重置武器进度。主武器强化和副武器威力升级对同类全部武器生效。

轻型机枪每发增加 4.5% 热量，达到 100% 时锁定，散热至 30% 后恢复。松手或过热时每秒降低 25% 热量。标准舰炮基础冷却 2.2 秒，其他武器有各自的热量与冷却参数，武器库展示实际伤害和射击间隔；装填升级会缩短冷却。进度条和倒计时显示在战场下方。暂停时热量与冷却计时冻结，新波次恢复就绪。

音效默认开启，点击开始战斗后激活，可在顶部静音并记住选择。包含机枪、主炮、爆炸、基地受击、过热报警、冷却完成、护盾与战役提示；由 `sea-audio.js` 使用 Web Audio 合成，无需额外音频下载。暂停、切到后台和关闭游戏会停止声音。

玩法参考：[海上保卫战中文版操作说明](https://www.7k7k.com/flash/29531.htm)。当前版本还原核心操作与战斗循环，关卡、数值、美术、音效由本项目重新设计。

## 账号和存档

用户名 3–24 位（中文、字母、数字、下划线或短横线），密码 8–128 位。注册成功即登录；退出后可切换账号。首页右上角和海战上方提供入口。游客模式直接开玩，无需注册；游客局不会转存到新账号。

服务端使用随机盐和 scrypt 存储密码摘要，HttpOnly / SameSite Cookie 保存会话标识。线上另启用 Secure。单机 JSON 文件原子写入；默认本地 `.data/`，线上 `/var/lib/play-island/`，不在公开文件目录。备份时需要同时备份 accounts.json 和 UUID 命名的存档文件，勿提交或公开该目录。会话有效期 7 天，服务重启后需重新登录，账号和存档不丢失。

存档包含波次、资金、升级、道具、耐久、敌舰、弹药与武器冷却，恢复时暂停。离线保存失败会明确提示并保留当前内存中的战局供重试；此时关闭浏览器可能丢失尚未保存的部分。多个窗口同时写入时拒绝覆盖旧版本，重新读取后继续。页面突然被系统关闭时，以最近一次成功保存为准。每个账号当前保留一个海战存档。

本版不含找回密码、邮箱验证或第三方登录。收藏、最近游玩等大厅偏好仍属于浏览器，不是账号战役存档。
